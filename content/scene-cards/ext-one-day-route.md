# Scene Card: ext-one-day-route

## Scene Role

Extension scene from Recommended Routes. This page explains a disciplined short-stay route.

## Core Point

One day in Jeju works best when the route chooses one coherent slice of the island.

## Audience Takeaway

The audience should understand that a one-day itinerary is about focus, travel-time discipline, and memorable pacing rather than maximum coverage.

## Visual Intent

A premium pixel route-atlas scene showing one compact route slice with clear start, movement, rest, and finish cues without embedded labels.

## Composition

Use a 16:9 atlas close-up or simplified island slice. The selected route should feel intentional and compact. Leave clear UI space away from the route spine.

## Must Include

- One focused regional route cluster
- Road/coastal movement cues
- Small car or bus/ferry hints
- Rest point or scenic stop cues
- Visual indication of omitted distance without text
- Hotspot-ready route sections if later needed

## Avoid

- Full-island checklist route
- Text labels, numbered stops, map legend, UI panels
- GPS app or subway diagram look
- Overly dense pins
- Generic road map detached from the pixel world

## Hotspot Plan

Phase one can stay terminal. Optional later hotspots may explain route tradeoffs, travel-time restraint, and weather fallback.

## UI Safe Zones

Reserve the right/upper-right side for content panel. Keep the route spine readable under collapsed UI.

## Art Prompt

Premium medium-resolution pixel art one-day Jeju route scene, 16:9 isometric 2.5D travel atlas style, cohesive with Jeju PixelFlip world, focused compact regional route slice, elegant road and coastal movement cues, small cars and rest points, clear pacing rhythm, intentionally omitted far regions implied by softer background, polished professional presentation background, clear route shape, calm right-side UI safe zone, no text, no labels, no numbers, no UI chrome.

## Negative Prompt

GPS app, subway diagram, numbered itinerary poster, text labels, map legend, pins everywhere, mobile game quest route, photorealistic satellite map, crude 8-bit graphics, cluttered checklist.

## Acceptance Criteria

- Scores at least 40/50 using `ART_DIRECTION_QA.md`
- Route discipline is visually clear
- Scene feels like a branch from Recommended Routes
- UI panel does not obscure the route spine
- Presenter can explain tradeoffs in 30-60 seconds
